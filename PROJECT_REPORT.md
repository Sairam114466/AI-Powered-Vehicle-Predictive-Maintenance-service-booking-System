# Final Year Project Report Summary

## Abstract

Vehicle breakdowns often occur without visible warning signs until the problem becomes severe. Traditional vehicle maintenance is either reactive, where repairs happen after failure, or preventive, where services are scheduled at fixed intervals without considering the actual condition of the vehicle. Both approaches can lead to unnecessary maintenance costs, safety concerns, and missed early warning signs. This project proposes an AI-based predictive maintenance system that uses machine learning to identify possible vehicle faults before they become serious.

The system analyses vehicle operating parameters such as engine speed, oil pressure, fuel pressure, coolant temperature, and temperature difference to determine the current health condition of the engine. A machine learning model is trained to classify the condition and provide a probability-based maintenance prediction. The system is implemented as a web application with a user-friendly dashboard that allows users to enter values and receive predictive analysis in real time.

The complete solution combines artificial intelligence, machine learning, and a simple interactive interface to move vehicle maintenance toward proactive care. This makes the project highly relevant for real-world use and suitable for a final-year engineering or computer science project.

## Introduction

Modern transportation depends heavily on vehicles for work, business, and daily life. However, most vehicle owners do not know the actual condition of their vehicle until a major issue appears. The common maintenance model is either periodic checking or repair after breakdown, which is not always efficient or safe. This creates unnecessary service costs and risks both financial loss and vehicle failure.

With the progress of artificial intelligence and machine learning, it is now possible to detect hidden patterns in data and predict possible faults before they occur. This project applies machine learning to vehicle maintenance by analysing operational data and identifying maintenance risk. The system aims to offer early warnings so users can take preventive action at the right time.

## Project Goal

The main goal of this project is to create a complete predictive maintenance application that helps users monitor vehicle condition, detect possible issues early, and reduce unplanned failures.

## Key Contributions

- AI-based predictive maintenance solution
- Machine learning classification model for vehicle condition
- User-friendly Streamlit interface
- Preventive service recommendation system
- Practical final-year project with real-world relevance

## Conclusion

This project demonstrates the potential of artificial intelligence in vehicle maintenance and highlights how predictive analytics can improve efficiency, reduce risk, and support smarter maintenance decisions. The integration of machine learning with a web-based interface makes the solution practical and suitable for final-year project presentation.
